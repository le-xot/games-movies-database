# Словарь «Вордли»

## Файлы

| Файл                 | Роль                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `answers-source.txt` | Вычитанный вручную список ответов (алфавитный порядок). **Правится только он.**              |
| `extra-words.txt`    | Ручной список догадок вне источников: заимствования и сленг, которых нет в словарях.         |
| `words.txt`          | Все допустимые догадки: слова из danakt и Harrix минус блэклист плюс ответы и `extra-words`. |
| `blacklist.txt`      | Обсценная лексика. Исключается из догадок; попадание в ответы ломает сборку.                 |
| `sources.json`       | Провенанс: URL источников, лицензии, SHA256 входных и сгенерированных файлов.                |
| `licenses/`          | Полные тексты лицензий источников (требование MIT при распространении).                      |

Списка ответов в порядке выпадения по датам в репозитории нет: `WordleDictionary`
строит его в рантайме, сортируя `answers-source.txt` по `sha256(слово + WORDLE_ANSWERS_SALT)`.
Соль живёт только в окружении сервера, поэтому по публичному репозиторию нельзя узнать,
какой ответ выпадет на конкретную дату.

## Формат

- UTF-8, LF, без BOM, одна запись на строку, без комментариев и пустых строк.
- Ровно 5 строчных букв `[а-я]`; `ё` нормализована в `е`.
- Дубликаты запрещены; `answers-source.txt ⊆ words.txt`, `extra-words.txt ⊆ words.txt`.
- Сборка падает на недопустимой записи в `extra-words.txt` и на пересечении
  `answers-source.txt` / `extra-words.txt` с `blacklist.txt`.
- Метаданные — только в этом README, внутри списков их быть не должно.

## Источники

| Источник               | Что берём                                | Лицензия | Файл лицензии                           |
| ---------------------- | ---------------------------------------- | -------- | --------------------------------------- |
| `danakt/russian-words` | допустимые догадки                       | MIT      | `licenses/danakt-russian-words-LICENSE` |
| `Harrix/Russian-Nouns` | допустимые догадки и кандидаты в ответы  | MIT      | `licenses/Harrix-Russian-Nouns-LICENSE` |
| ручная вычитка         | `extra-words.txt` (заимствования, сленг) | проекта  | —                                       |

Частотные списки (в т.ч. CC-BY-SA и данные OpenSubtitles) сознательно не используются:
юридически чище обойтись MIT-источниками. Определения слов тоже не используются —
это чужой текст толковых словарей.

`extra-words.txt` закрывает то, чего в словарях нет: современные заимствования и сленг
(«свайп», «смузи», «крафт», «кринж»). Слова оттуда — только догадки, ответами они
становятся лишь через `answers-source.txt`.

## Как обновить

1. При необходимости дополнить `answers-source.txt` или `extra-words.txt` вручную
   (критерии ниже).
2. Запустить сборку из корня репозитория:

   ```bash
   bun run backend/src/modules/wordle/scripts/build-dictionary.ts
   ```

3. Проверить `git diff` и `sources.json`, прогнать `cd backend && bun test`.

Посмотреть всех кандидатов в ответы (5-буквенные существительные из Harrix):

```bash
bun run backend/src/modules/wordle/scripts/build-dictionary.ts --candidates
```

## Порядок ответов

- Порядок задаёт переменная окружения `WORDLE_ANSWERS_SALT`: в production она
  обязательна, при `NODE_ENV=development` подставляется небезопасный дефолт.
- Смена соли полностью ротирует расписание на будущие даты. Уже сыгранные игры не
  ломаются: ответ каждой игры хранится в БД.
- Соль генерировать длинной и случайной, например: `openssl rand -hex 32`.
- Старые значения соли и прежние порядки, оставшиеся в истории git, после ротации
  бесполезны.

## Критерии отбора ответов

Оставляем частотные современные существительные в начальной форме (им. падеж, ед. ч.),
понятные взрослому носителю. Не берём: формы косвенных падежей, имена и топонимы,
узкую терминологию, устаревшее и диалектное, обсценное, слова преимущественно других
частей речи (омонимы предлогов/глаголов/наречий вроде «через», «стать», «плохо»),
уменьшительные без самостоятельного значения.

Потолок списка ответов — 5-буквенные существительные Harrix (3473 штуки). Почти всё,
что в него не попало, — диалектное и устаревшее, поэтому расширять список дальше
без нового источника нечем.

## Критерии отбора догадок

Догадкой годится любое слово, которое человек может набрать: диалектное и устаревшее
тоже принимаем (это не ломает игру), кроме обсценного из `blacklist.txt`.
В `extra-words.txt` кладём только то, чего нет в словарях: заимствования, сленг и
профессиональный жаргон, понятные носителю. Формат — как у остальных списков;
сборка падает на слове не из пяти букв, так что опечатку видно сразу.
