# SERVER LAYER

## OVERVIEW

Обвязка вокруг Elysia-гейтвея: сборка зависимостей, HTTP-конвейер, статика и
порты домена. Домен (`modules/`) про этот слой не знает; направление
зависимостей — только `server → gateway → modules`.

```
server/
├── container.ts   # composition root: создать сервисы, повесить хуки, вернуть порты
├── wiring/        # порты по доменам: query/body → аргументы сервиса
├── http.ts        # Elysia: CORS, security-заголовки, /api, JSON-404, статика
└── static.ts      # SPA-фолбэк + защита от выхода за корень
```

## ГЛАВНОЕ ПРАВИЛО: ФОРМА ДАННЫХ

Схема TypeBox — **единственный источник типов фронта**: Eden выводит их из
`static`. Поэтому наружу уходит ровно то, что описано в схеме, и ничего больше.

- **Даты — ISO-строки и в домене.** Колонки объявлены через `isoTimestamp`
  (`database/src/schema/timestamp.ts`), поэтому сущности уже несут `string`.
  Конвертации на выходе нет и быть не должно.
- **Не использовать `t.Date()` и `t.Transform` в ответах.** Первый ломает
  контракт (`type: "Date"`), второй делает `static` типом `Date` — фронт
  получит `Date`, а по проводу придёт строка.
- **Не возвращать `Date` из обработчика.** Схема ответа этого не пропустит,
  а `onAfterHandle`-магии здесь нет намеренно.

## КАК ДОБАВИТЬ ЧТО-ТО

| Задача                 | Что делать                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Новый доменный сервис  | Создать в `container.ts` (обычный `new`, зависимости в конструктор), добавить в список хуков, если есть `onModuleInit` |
| Новый порт для гейтвея | Добавить метод в интерфейс порта (`gateway/<домен>.ts`) и реализовать в `wiring/<группа>.ts`                           |
| Новая группа портов    | Завести `wiring/<группа>.ts` и развернуть его в `deps` через `...xxxPorts({...})`                                      |
| Роут                   | Только в `gateway/<домен>.ts`; `server/` роутов не содержит                                                            |

## ХУКИ ЖИЗНЕННОГО ЦИКЛА

Nest вызывал `onModuleInit` / `onApplicationBootstrap` / `onModuleDestroy` сам.
Теперь это делает `container.init()` и `container.close()` по явным спискам
`started` / `stoppable`. Новый сервис с прогревом или таймером **обязательно**
добавить в соответствующий список, иначе он просто не запустится.

Ошибка в хуке не валит старт приложения (в отличие от Nest): пишем warning и
идём дальше — недоступная погода или Telegram не должны ронять сайт.

## ANTI-PATTERNS

- **Не импортировать `modules/*` в `gateway/*`** — гейтвей знает только порты;
  исключение — типы, и то через `server/wiring`.
- **Не класть бизнес-логику в `wiring/`** — только приведение формы запроса.
- **Не возвращать в `http.ts` plain-text 404 под `/api`** — контракт обещает
  `ApiErrorDto`.
- **Не создавать `pg.Pool` вне `DrizzleService`.**
