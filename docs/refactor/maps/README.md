# Карты рекона — снимок, а не текущее состояние

Эти файлы собраны на ветке `chore/code-cleanup` в начале кампании
(`master e73dcfb`) и описывают **исходную** энтропию. Они не обновляются задним
числом: источник правды о текущем состоянии — `../tasks.md` (пул и «Сделано»),
`../progress.md` (раунды) и сам код с машинными ловушками.

| Карта                     | Что описывает                             | Что уже неактуально (см. «Сделано» в tasks.md)                                   |
| ------------------------- | ----------------------------------------- | -------------------------------------------------------------------------------- |
| `backend.md`              | слои gateway/modules/server, порты, дубли | B-01…B-14: ошибки, lifecycle, enum SSOT, class-DTO, rate-limit, дата очереди     |
| `frontend.md`             | страницы, состояние, дубли UI/данных      | F-01…F-12: списки, ошибки, реестр жанров, словарь, заголовок, модалки, DataCards |
| `contract-data-config.md` | contract/pgEnum/api-types/env/seed/CI     | C-02/C-03: api-types сужен, enum-инвариант; seed и env — вне MVP-кампании        |
| `hygiene.md`              | мёртвое, циклы, дубли, крупные файлы      | мёртвый код вычищен (G-01), циклы/дубли — частично, закрыто задачами выше        |

Правило: при закрытии задачи с картой сверяемся, но правки в карту не вносим —
устаревший снимок честнее поддельной актуальности. Если нужен новый обзор —
собирается новым реконом, а не патчем старого.
