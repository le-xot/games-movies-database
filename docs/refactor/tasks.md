# Пул задач

Статусы: `todo` → `doing` → `review` → `done`; `blocked` — ждёт решения владельца;
`dropped` — отвергнута (причина обязательна).

Правила: одна задача = один батч = один commit. Блокирующие зависимости — в колонке Deps.
Evidence — в картах `maps/`; здесь только суть и ссылка на ID находки.
P1 — латентные баги и мёртвый код; P2 — канонизация с прямой выгодой; P3 — границы и SSOT;
P4 — уборка, требующая решения; P5 — гигиена/наблюдаемость.
